# GPT Blend

AI-powered Blender add-on for connecting Blender to OpenAI GPT models.

## Prototype

The prototype provides a Blender sidebar chat UI, model selection, API key configuration, OpenAI Responses API integration, and basic Blender scene context.

## Installation
1. Download or clone this repository.
2. Zip the gptblend folder and install it from Blender Preferences > Add-ons > Install.
3. Enable GPT Blend.
4. Open the 3D View sidebar (N) and select GPT Blend.
5. Configure your OpenAI API key in Preferences.

Never commit your API key.

Blender tool-calling will be added after the API connection is proven stable.
