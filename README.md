# GPT Blend\n\n**AI-powered Blender add-on for controlling Blender with OpenAI GPT models using natural language.** GPT Blend connects Blender to the OpenAI API and turns natural-language instructions into structured Blender operations for modeling, materials, cameras, lighting, animation, scene organization, rendering, and visual inspection.\n\n> **Blender + AI + OpenAI** — build, edit, inspect, animate, light, and organize Blender scenes through natural-language commands.\n\n## Why GPT Blend?\n\nGPT Blend is a **Blender AI assistant / BlenderGPT-style add-on** for users who want to work with Blender through natural language. Instead of only asking a model to generate Python code, GPT Blend gives the model a structured tool layer for Blender operations and can verify important changes afterward.\n\n### Highlights\n\n- **70 model-facing Blender tools** for scene creation, modeling, mesh editing, materials, cameras, lighting, animation, constraints, collections, and rendering.\n- **OpenAI Responses API** integration with persistent multi-turn agent sessions.\n- **Natural-language Blender control** from the Blender sidebar.\n- **Visual context** with optional 3D Viewport screenshots.\n- **Multi-step AI agent workflows** with tool calling and verification.\n- **Animation support** tested in a real Blender 5.2.2 LTS runtime.\n- **Undo checkpoints and destructive-operation controls** for safer AI editing.\n- Background network/model work so waiting on the OpenAI API does not intentionally block Blender's UI thread.\n- Model picker for the API models exposed by the current GPT Blend release.\n\n## Search terms / what GPT Blend is\n\nGPT Blend is a **Blender AI assistant**, **BlenderGPT alternative**, **ChatGPT for Blender**, **AI Blender add-on**, **OpenAI Blender plugin**, and **natural-language Blender automation tool**. It is intended for Blender users who want AI-assisted modeling, scene setup, materials, animation, cameras, lighting, rendering, and Blender scripting workflows.\n\n## GPT Blend 0.7.0\n\nGPT Blend uses OpenAI function calling / tool calling to let the selected GPT model operate Blender through a structured tool layer instead of returning only Python code.\n\n### Agent features\n\n- Up to **100 model/tool continuation rounds** per request by default.\n- **150 total tool-call safety cap** by default.\n- Optional repeated-call loop protection.\n- Automatic retries for transient network/API failures.\n- Persistent multi-turn sessions using the Responses API response chain.\n- Retry the last failed/cancelled prompt without retyping it.\n- Copy GPT responses directly to the clipboard.\n- Show API-reported token usage when available.\n- Model-specific sessions.\n- Manual **New Chat** control.\n- Persistent in-panel chat history.\n- Live tool activity log with tool-call count.\n- Clean cancellation and session reset.\n- Optional viewport screenshot context for visual reasoning.\n- Blender undo checkpoints before GPT-driven edits.\n\n## Blender AI capabilities\n\n### 3D modeling and Blender tool-calling architecture**:\n\n1. Collect relevant scene context.\n2. Optionally capture the active 3D Viewport.\n3. Send the request to the OpenAI Responses API.\n4. Let the model select structured Blender tools.\n5. Execute Blender tools on Blender's main thread.\n6. Return structured tool results to the model.\n7. Verify important mutations.\n8. Continue until the task is complete, a safety limit is reached, or an error occurs.\n\nThis lets GPT Blend handle multi-step Blender tasks rather than forcing the user to manually execute every generated operation.\n\n## OpenAI and ChatGPT model support\n\nGPT Blend talks directly to the **OpenAI API**; it is not a browser wrapper around ChatGPT.\n\nOpenAI model availability and API IDs can change independently of GPT Blend. Current OpenAI documentation distinguishes ChatGPT product models from API model IDs, so GPT Blend documents the exact API models exposed by each release rather than assuming that a ChatGPT model name can be sent directly to the API.\n\nOfficial references:\n\n- https://platform.openai.com/docs/models\n- https://help.openai.com/en/articles/20001354-gpt-5-6\n\n### GPT Blend 0.7.0 built-in model picker\n\n| GPT Blend option | API model ID |\n| --- | --- |\n| GPT-5.6 Luna | `gpt-5.6-luna` |\n| GPT-5.6 Sol | `gpt-5.6-sol` |\n| GPT-5.6 Terra | `gpt-5.6-terra` |\n\nThe README also tracks the current ChatGPT model naming landscape, including **GPT-6 Astra** and GPT-6 Sol/Luna where documented by OpenAI. The built-in picker should only list API IDs that the current GPT Blend release actually supports.\n\n## Installation\n\n### Install in Blender\n\n1. Download the latest GPT Blend extension ZIP from the repository's successful package build.\n2. Open **Blender 5.2 or newer**.\n3. Go to **Edit → Preferences → Get Extensions**.\n4. Choose **Install from Disk**.\n5. Select the GPT Blend `.zip` file.\n6. Enable GPT Blend.\n7. Open the 3D View Sidebar with **N**.\n8. Open the **GPT Blend** panel.\n9. Enter your OpenAI API key in Preferences.\n10. Select the API model and send a natural-language request.\n\nExample:\n\n> Create a beveled wooden table with four legs, place an Area light above it, create a camera, and set the render to 1920x1080.\n\n### Developer installation\n\nClone the repository and work from the `gptblend/` extension directory. Runtime tests and the CI packaging workflow are included in the repository.\n\n## Example prompts\n\n- “Create a stylized low-poly castle with towers and a courtyard.”\n- “Build a wooden table with four legs, a beveled top, and a simple material.”\n- “Make the selected object blue, metallic, slightly rough, and smoothly shaded.”\n- “Mirror this mesh across X and add a small bevel.”\n- “Use this object as a Boolean cutter and subtract it from the main mesh.”\n- “Arrange these objects in a straight line with 2 meters between each.”\n- “Create an Area light above the model and aim a camera at it.”\n- “Animate this object moving from left to right over 60 frames.”\n- “Add a looping rotation animation to the selected object.”\n- “Inspect the selected object and explain its modifiers and materials.”\n- “Set the render to 1920x1080 at 60 FPS.”\n- “Organize the scene into Environment, Characters, and Props collections.”\n- “Look at the current viewport and tell me what stands out visually.”\n\n## BlenderGPT alternatives and positioning\n\nGPT Blend is built for users searching for a modern **BlenderGPT / Blender AI assistant** workflow. Compared with a simple text-to-Python approach, GPT Blend focuses on structured Blender tools, multi-step agent loops, verification, Blender 5.2 compatibility, and safety controls.\n\nThe project is open source and intended to be inspectable, testable, and extensible.\n\n## Safety\n\nGPT Blend uses structured Blender operations rather than unrestricted generated Python for its model-facing tool layer. The model is instructed to avoid unnecessary edits and not delete objects unless deletion is explicitly requested.\n\nMutating operations create Blender undo checkpoints when Blender permits them. Destructive operations can also be gated by a preference.\n\nThese controls reduce the risk of runaway tool loops and unintended edits, but users should still review important AI-generated changes.\n\n## Visual context\n\nWhen enabled, GPT Blend can capture the active 3D View and provide it as additional model context.\n\nThis is useful for:\n\n- composition;\n- object placement;\n- visible geometry;\n- viewport state;\n- visual troubleshooting.\n\n## Verification\n\nImportant operations can be automatically verified after execution. For example, animation changes can be followed by animation inspection, object mutations by object inspection, and scene-wide changes by scene inspection.\n\nVerification is included in the overall tool-call safety budget.\n\n## UI\n\nThe GPT Blend sidebar includes:\n\n- connection status;\n- model selector;\n- session state;\n- tool-call count;\n- elapsed time;\n- API token usage when available;\n- chat history;\n- live activity log;\n- response display;\n- Send;\n- Stop;\n- Retry;\n- Copy Response;\n- New Chat;\n- Clear.\n\n## Troubleshooting\n\n### Animation or Blender API errors\n\nRestart Blender after installing a newer GPT Blend build so the updated Python modules are loaded.\n\n### API errors\n\nCheck the OpenAI API key, selected API model, network connection, and whether the selected model is available to your OpenAI account.\n\n### Repeated tool calls\n\nEnable loop protection and reduce the maximum agent rounds or total tool calls.\n\n### Materials look different in the viewport\n\nSome material operations intentionally switch viewport shading so changes become immediately visible. Shared Blender materials can affect multiple objects.\n\n## Developer structure\n\n| Path | Responsibility |\n| --- | --- |\n| `gptblend/core/client.py` | OpenAI Responses API client and agent/tool loop |\n| `gptblend/core/async_agent.py` | Worker-thread orchestration |\n| `gptblend/tools/schemas.py` | Model-facing tool definitions |\n| `gptblend/tools/blender_ops.py` | Blender tool implementations |\n| `gptblend/tools/registry.py` | Tool registry |\n| `gptblend/context/scene.py` | Scene context |\n| `gptblend/context/viewport.py` | Viewport image capture |\n| `gptblend/ui/operators.py` | Blender operators and async polling |\n| `gptblend/ui/panel.py` | Sidebar UI |\n| `gptblend/preferences.py` | API/model/safety preferences |\n| `tests/test_animation_runtime.py` | Real Blender animation runtime test |\n| `tests/validate_tool_surface.py` | Tool/schema consistency test |\n| `.github/workflows/validate.yml` | CI validation and extension packaging |\n\n## CI and quality\n\nEvery push/pull request runs structural Python validation and a Blender 5.2.2 runtime test.\n\nThe package job validates the Blender extension manifest, builds an installable extension ZIP, and uploads it as a GitHub Actions artifact.\n\n## Privacy and API keys\n\nGPT Blend sends your prompts and selected scene/viewport context to the OpenAI API when you use it.
